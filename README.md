# 📚 Nicely Mini Library Management System

## 📝 About The Project
Nicely Mini Library System is a desktop application built to streamline library operations. It features a dual-role architecture, providing customized interfaces and functionalities for both Administrators and Students, ensuring efficient data management and an intuitive user experience.

## ✨ Key Features
*   **Dual Role Access:** Secure login system differentiating between `Admin` and `Student` accounts.
*   **Admin Dashboard:** Empowers administrators to manage library inventory, track user records, and oversee daily operations.
*   **Student Portal:** Allows students to easily search for available resources and view their borrowing status.
*   **Advanced Report Form:** Features dynamic search filters and data export capabilities for administrative record-keeping.
*   **Database Integration:** Fully integrated with a MySQL database for robust data storage and retrieval.

## 🛠️ Built With
*   **Programming Language:** Visual Basic .NET (VB.NET)
*   **Database:** MySQL

## 🚀 How to Run the Project
1. Clone the repository to your local machine.
2. Import the `nicelymini.sql` file into your local MySQL database (e.g., using XAMPP/phpMyAdmin).
3. Open the `.sln` file in Visual Studio.
4. Update the database connection string in `DBConnection.vb` if necessary.
5. Build and Run the application.
